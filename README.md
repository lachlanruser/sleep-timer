# Sleep Timer

A calm, phone-first bedtime routine timer. Tap a slice of the circle to run that task's timer; finish every slice to keep your streak. It keeps the screen awake while a timer runs.

Plain HTML/CSS/JS, no build step, no server. Your data stays in your browser's local storage on your device.

- Run locally: `powershell -NoProfile -ExecutionPolicy Bypass -File tools\serve.ps1`, then open http://localhost:5190/ (add `?fast` for 2-second minutes).
- Tests: open http://localhost:5190/tests/
